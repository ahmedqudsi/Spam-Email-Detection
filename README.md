# Spam-Email-Detection (Machine Learning Model)

# 🧠 Model Overview

Text preprocessing using NLP techniques

Feature extraction with CountVectorizer

Classification using Multinomial Naive Bayes

Trained on a labeled email spam dataset

# 🛠 Tech Stack

Python

Pandas, NumPy

Scikit-learn

Jupyter Notebook

# 📊 Output

Predicts whether an email is Spam or Not Spam

Demonstrates end-to-end ML pipeline: preprocessing → training → evaluation

🎯 Use Case

Designed to showcase core text classification and NLP modeling skills for academic and portfolio purposes.
